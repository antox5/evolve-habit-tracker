# 🚀 Evolve! — Modern Habit Tracker & Growth Companion

**Evolve!** is a high-performance, cross-platform mobile application designed to help users build discipline, maintain consistency, and track daily personal growth. Built with Flutter, Firebase, and state-of-the-art state management architecture.

## ✨ Features

- 📅 **Habit Tracking:** Set up, track, and manage your daily habits seamlessly.
- 🔥 **Consistency & Streaks:** Visualize progress and build long-term momentum.
- 💡 **Instant Motivation:** Trigger random motivational quotes on demand powered by the **ZenQuotes API** and dynamic overlay toasts.
- ☁️ **Cloud Synchronization:** Real-time data persistence powered by **Google Cloud Firestore**.
- 🎨 **Sleek UI/UX:** Clean, intuitive interface with custom notifications powered by `toastification`.

---

## 🛠️ Tech Stack & Architecture

- **Framework:** [Flutter](https://flutter.dev/) (Dart)
- **State Management:** BLoC / Cubit Pattern
- **Backend & Database:** Google Cloud Firestore
- **API Integration:** ZenQuotes API (`https://zenquotes.io/api/random`)
- **UI Notifications:** `toastification` (^2.3.0)

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your development machine:
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (latest stable version)
- [Dart SDK](https://dart.dev/get-started/sdk)
- [Android Studio](https://developer.android.com/studio) or [VS Code](https://code.visualstudio.com/)
- Active Firebase Project with Cloud Firestore enabled
